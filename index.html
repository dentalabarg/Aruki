Cotizaciones Preparando

Se cargan los artículos y las relaciones al abrir este módulo.

1. Cargá la lista del cliente
Subí el archivo del cliente o arrastralo acá Excel, Word, PDF o texto. Aruki lo lee y arma el presupuesto solo.
Aruki busca primero en Relaciones y después por parecido en todos los artículos.
2. Revisá el presupuesto · 0 renglones

Arrastrá desde ⠿ para cambiar el orden. Para cambiar un artículo tocá el SKU o el nombre y buscá. Podés editar el texto adicional y la cantidad. Para cambiar el ancho de una columna arrastrá el borde del título (doble clic vuelve al ancho original). Cuando hay dudas aparecen varias opciones para el mismo renglón: elegí una con ✓ o borrá las que no sirvan.
